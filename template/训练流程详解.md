# 完整训练流程详解

## 概览

你的训练流程分为 **3 个 Pass（遍历）**：

1. **Pass 1**: 扫描元数据 - 发现特征列和日期边界
2. **Pass 2**: 拟合预处理器 - 计算标准化/填充参数
3. **Pass 3**: 构建 Memmap 缓存 - 预处理数据 + 构建窗口索引

然后 **训练**、**验证**、**测试**。

## 二、详细流程

### Pass 1: 扫描元数据（~5 秒）

**目的**: 发现特征列、日期边界，无需加载实际数据

**代码位置**: `template/data/io_parquet.py` 中的 `scan_train_metadata()`

**步骤**:

1. **发现特征列** (`discover_factor_columns`)
   - 读取 parquet schema，找出所有 `f0` ~ `f383` 格式的列
   - 按数字大小排序，返回 384 个特征列列表

2. **筛选特征** (`select_feature_columns`)
   - **mode = "no_missing"**（你的设置）
   - 从预定义列表中选出 **81 个无缺失特征**：
     ```
     f29, f41, f46, f47, f48, f58, f59, f61,
     f170-f173, f219, f223, f230, f235-f238,
     f258-f266, f270, f273, f274, f279-f283,
     f286-f287, f290, f292, f297-f300, f313-f325,
     f334-f336, f338-f346, f350, f354-f373
     ```
   - 其他 mode 选项：
     - `"all"`: 全部 384 个特征
     - `"top_ic"`: 仅 8 个 IC 分数最高的特征
     - `"custom"`: 用户指定的特征列表

3. **扫描日期边界** 
   - 逐批读取 train.parquet 的 dateid 列
   - 收集所有唯一日期，排序
   - 按 70%:15%:15% 比例分割：
     ```
     train_end = dates[int(len(dates) * 0.70) - 1]
     val_end   = dates[int(len(dates) * 0.85) - 1]
     test_end  = dates[-1]
     ```
   - 假设共 ~200 个交易日，则：
     - train: dateid ≤ day140
     - val:   day140 < dateid ≤ day170
     - test:  dateid > day170

**输出**: `feature_cols`（81 个特征）、`train_end`、`val_end`

---

### Pass 2: 拟合预处理器（~2 秒）

**目的**: 计算标准化参数（均值、标准差、中位数等），无需存储原始数据

**代码位置**: `template/data/preprocess.py` 中的 `fit_preprocessor_streaming()`

**步骤**:

1. **流式读取训练数据**（Welford 并行算法）
   - 批量读取 train.parquet，每批 200K 行
   - 过滤掉 dateid > train_end 的行
   - 对每个特征列计算：
     - **均值** (mean)
     - **标准差** (std) 
     - **中位数** (median)
   - 使用 Welford 算法，无需存储全部数据

2. **缺失值填充参数**
   - `fillna_strategy = "median"`
   - 为每个特征计算中位数
   - 在预处理时用中位数替换 NaN

3. **标准化参数**
   - `standardize = True`
   - `standardize_mode = "cross_section"`
   - **模式说明**：
     ```
     "none"           → 不标准化
     "global"         → (x - mean) / std (整个训练集统一)
     "cross_section"  → 按(dateid, timeid)分组，各组独立标准化
     "date"           → 按 dateid 分组，每天单独标准化
     "time_rolling"   → 按股票和日期的滚动窗口标准化（金融常用）
     ```
   - 默认使用 "cross_section"：
     - 对于每个 (dateid, timeid) 的所有样本
     - 计算该截面的均值和标准差
     - 然后 z-score 标准化：(x - 截面均值) / 截面标准差
     - **好处**: 消除跨日期的绝对值差异，保留相对排名

4. **分位数裁剪**（可选，你没用）
   - 如果 `clip_quantile = 0.95`
   - 计算 2.5% 和 97.5% 分位数
   - 训练时超出范围的值被裁剪

**输出**: `PreprocessorState` 对象，包含：
```python
{
  "fillna_strategy": "median",
  "standardize": True,
  "standardize_mode": "cross_section",
  "medians": {f29: 0.123, f41: -0.456, ...},  # 81 个值
  "means": {...},     # 截面标准化时为空
  "stds": {...},      # 截面标准化时为空
}
```

---

### Pass 3: 构建 Memmap 缓存（~7 秒）

**目的**: 一次性预处理全部数据，存储为内存映射文件 + 窗口索引

**代码位置**: `template/data/memmap_dataset.py` 中的 `build_memmap_cache()`

#### 3a. 数据预处理与写入

1. **逐行组读取与预处理**（按 stockid 分组）
   - parquet 分为 500 个行组，每组 1 只股票
   - 对每个行组：
     1. 读取所有行（~86K 行）
     2. 按 (dateid, timeid) 排序（保证时间顺序）
     3. 应用 Pass 2 的预处理参数：
        ```python
        # 填充
        data[NaN] = medians  # 中位数填充
        
        # 标准化（按截面）
        for each (dateid, timeid):
            subset = data[data.dateid == d and data.timeid == t]
            mean = subset.mean()
            std = subset.std()
            data[subset] = (data[subset] - mean) / std
        ```
     4. 裁剪异常值（可选）
     5. 转换为 float32
     6. 写入 memmap 文件

2. **Memmap 文件结构**
   ```
   文件: cache/memmap/preprocessed.dat (~14GB)
   
   行数: 43,020,000（全部数据）
   列: [f0~f80: 81个特征 | LabelA: 1列标签 | stockid: 1列 | dateid: 1列]
   共 84 列，float32 类型
   
   按股票顺序写入，每只股票内按日期时间排序
   ```

#### 3b. 窗口索引构建

1. **验证日期连续性**
   - 对每只股票的每个交易日
   - 检查该日的样本是否连续（中间无跳跃）
   
2. **构建滑动窗口**
   - `lookback = 32`（默认）
   - `cross_date_windows = False`（不跨日期）
   
   **窗口规则**：
   ```python
   for each stock s:
       for each date d:
           day_samples = data[stock==s and date==d]
           if len(day_samples) < 32:
               continue  # 样本太少，跳过
           
           # 对于该日的所有样本
           for i in range(len(day_samples) - 32 + 1):
               window_start = global_row_index
               # 该窗口包含该日的 32 个连续样本
               # 最后一个样本的日期和时间决定了 split
               
               if d <= train_end:
                   train_indices.append(window_start)
               elif d <= val_end:
                   val_indices.append(window_start)
               else:
                   test_indices.append(window_start)
   ```

3. **索引文件**
   ```
   cache/memmap/idx_train.npy  → ~600k windows（训练集窗口起始位置）
   cache/memmap/idx_val.npy    → ~200k windows（验证集）
   cache/memmap/idx_test.npy   → ~200k windows（测试集）
   ```

4. **例子**
   ```
   stock 0, day 100, timeid 0-238:
     如果有 239 个样本，可以构造 239-32+1=208 个窗口
     每个窗口 = 连续 32 行（从该日的样本中取）
   ```

**输出**: memmap 文件 + 三个索引文件 + 元数据 JSON

## 三、模型架构详解（Autoformer_encoder）

### 整体结构

```
输入 [batch_size=512, lookback=32, features=81]
  ↓
[Conv1d Block] (捕捉局部趋势)
  - Conv1d: 81 → 81 channels, kernel_size=5
  - ReLU + Dropout
  - 残差连接
  ↓
[FC 投影] (特征投影)
  - Linear(81 → 128)
  - LayerNorm
  ↓
[位置编码] (添加位置信息)
  - 正弦/余弦位置编码
  ↓
[Autoformer Encoder Stack] (2 层)
  ├─ Layer 1:
  │  ├─ AutoCorrelation 注意力
  │  ├─ FFN (前馈网络)
  │  └─ 残差+LayerNorm
  └─ Layer 2: (同上)
  ↓
[取最后时间步] 
  - output[:, -1, :] → [batch, 128]
  ↓
[FC 头部] (回归)
  - LayerNorm(128)
  - FC_residual (残差全连接)
    - Linear(128 → 512)
    - ReLU
    - Dropout
    - Linear(512 → 128)
    - LayerNorm
    - 残差: 128 + (512→128) = 128
  - Linear(128 → 1)
  ↓
输出 [batch_size, 1] (预测值)
```

### 参数数量估算

```
Conv1d(81→81, k=5):           ~2K
FC(81→128) + LN:               ~10K
PositionalEncoding:            ~1K
AutoCorrelation × 2:
  - 投影 + Q/K/V:              ~200K
  - FFN (Dense):               ~300K
FC 头部:
  - LN + FC(128→512):          ~65K
  - FC(512→128):               ~65K
  - Final(128→1):              ~0.1K
─────────────────────
总参数量:                       ~640K
```

### 前向传播步骤

```python
def forward(src, ids):
    # 输入: src [512, 32, 81]
    
    # 1. Conv1d 处理
    src = src.permute(0, 2, 1)  # [512, 81, 32]
    src = conv1d(pad(src))       # [512, 81, 32]
    src = src.permute(0, 2, 1)   # [512, 32, 81]
    
    # 2. 投影
    src = fc_in(src)             # [512, 32, 128]
    
    # 3. 位置编码
    src = src.transpose(0, 1)    # [32, 512, 128]
    src = pos_encoder(src)        # 加入位置信息
    src = src.transpose(0, 1)    # [512, 32, 128]
    
    # 4. Encoder 栈
    src = encoder(src)            # [512, 32, 128]（经过 2 层）
    
    # 5. 取最后时间步
    h = src[:, -1, :]            # [512, 128]
    
    # 6. 可选: 加入股票 embedding（默认不用）
    if use_emb:
        e = emb(ids)             # [512, emb_dim]
        h = concat([h, e], dim=1)
    
    # 7. FC 头部
    h = dropout(h)               # [512, 128]
    y = head(h)                  # [512, 1]
    
    return y
```

## 四、数据集划分详解

### 时间序列划分原则

**重要**: 这是**时间序列预测**，必须保证：
- 训练样本的时间 < 验证样本的时间 < 测试样本的时间
- **禁止使用未来信息**（向前看偏差）

### 日期边界计算

假设 train.parquet 共包含 **200 个交易日**（dateid = 0~199）

```python
unique_dates = [0, 1, 2, ..., 199]  # 200 个日期
train_idx = max(1, int(200 * 0.70) - 1) = 139  # 第 140 个日期
val_idx = max(139+1, int(200 * 0.85) - 1) = 169  # 第 170 个日期

train_end = dates[139] = 139
val_end = dates[169] = 169
```

### 样本分配

```
训练集 (train):
  - dateid ≤ 139（第 0~139 日）
  - 窗口数: ~358,479 个
  - 模型在这些窗口上计算损失和更新参数

验证集 (val):
  - 139 < dateid ≤ 169（第 140~169 日）
  - 窗口数: ~119,493 个
  - 每个 epoch 后在验证集上评估，用于早停和模型选择

测试集 (test):
  - dateid > 169（第 170~199 日）
  - 窗口数: ~119,493 个
  - 最终评估指标，生成提交文件
```

### 窗口与样本对应

```
一个"窗口"对应一个神经网络输入样本：

窗口 1: 
  - 股票 0, 日期 100, 时间 [0-31]
  - 输入: 32 行数据 [时间0~31 的特征]
  - 标签: 时间 31 的 LabelA
  
窗口 2:
  - 股票 0, 日期 100, 时间 [1-32]
  - 输入: 32 行数据 [时间1~32 的特征]
  - 标签: 时间 32 的 LabelA

...（同一日期内可以有多个重叠窗口）

日期内样本数量:
  - 如果一个交易日有 239 个样本（timeid 0~238）
  - 可构造窗口数 = 239 - 32 + 1 = 208 个
```

## 五、预处理详解

### 缺失值处理

```python
fillna_strategy = "median"

# 对每个特征
for feature in [f29, f41, ..., f373]:  # 81 个特征
    median_value = train_data[feature].median()
    data[feature][NaN] = median_value
```

**为什么用中位数?**
- 比均值更稳健（不受极端值影响）
- 金融数据中价格/量级差异大

### 标准化详解

```python
standardize = True
standardize_mode = "cross_section"

# 对每个 (dateid, timeid) 组合
for d in unique_dates:
    for t in unique_timeid:  # 0-238
        subset = data[(data.dateid == d) & (data.timeid == t)]
        
        # 该截面的统计量
        mean = subset[feature_cols].mean()
        std = subset[feature_cols].std()
        
        # Z-score 标准化
        subset[feature_cols] = (subset[feature_cols] - mean) / std
        
        # 防止分母为 0
        std[std < 1e-12] = 1.0
```

**截面标准化的优势（金融量化）**:
- 消除跨日期的绝对值变化
- 保留**相对排名**信息（对排序预测重要）
- 例: 同一时刻所有股票的特征分布都被标准化为均值 0、方差 1
- 这样模型学到的是"相对强弱"而非绝对值

## 六、训练流程

### 初始化

```python
# 模型
model = Autoformer_encoderModel(
    num_indices=500,        # 500 只股票（用于 embedding，但 emb_dim=0 所以没用）
    num_features=81,        # 81 个特征
    hidden=128,             # 隐层维度
    num_layers=2,           # encoder 层数
    drop_out=0.2,
)

# 优化器
optimizer = AdamW(
    model.parameters(),
    lr=1e-3,
    weight_decay=1e-5
)

# 损失函数
loss_fn = MSELoss()  # (预测 - 真实)^2

# 设备
device = "cuda"  # GPU
```

### 每个 Epoch 的训练

```python
for epoch in range(1, 9):  # 8 个 epoch
    # ── 训练阶段 ──
    model.train()
    train_loss = 0.0
    
    # DataLoader 自动从 memmap 中取样本
    for batch_idx, (X, ids, y) in enumerate(train_loader):
        # X: [512, 32, 81] 特征序列
        # ids: [512] 股票 ID
        # y: [512, 1] 真实标签
        
        X, ids, y = X.to(device), ids.to(device), y.to(device)
        
        optimizer.zero_grad(set_to_none=True)
        
        # 混合精度
        with autocast(device_type='cuda', dtype=torch.bfloat16):
            pred = model(X, ids)  # [512, 1]
            loss = loss_fn(pred, y)
        
        # 反向传播
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()
        
        train_loss += float(loss.item()) * len(X)
    
    avg_train_loss = train_loss / len(train_dataset)
    
    # ── 验证阶段 ──
    model.eval()
    val_loss = 0.0
    val_preds = []
    val_targets = []
    
    with torch.no_grad():
        for X, ids, y in val_loader:
            X, ids, y = X.to(device), ids.to(device), y.to(device)
            pred = model(X, ids)
            loss = loss_fn(pred, y)
            val_loss += float(loss.item()) * len(X)
            val_preds.append(pred.cpu().numpy())
            val_targets.append(y.cpu().numpy())
    
    avg_val_loss = val_loss / len(val_dataset)
    
    # 计算指标
    val_preds_all = np.concatenate(val_preds)
    val_targets_all = np.concatenate(val_targets)
    r2 = r2_score(val_targets_all, val_preds_all)
    
    print(f"Epoch {epoch}: train_loss={avg_train_loss:.6f}, "
          f"val_loss={avg_val_loss:.6f}, val_r2={r2:.4f}")
```

### 损失函数

```python
MSE = mean((pred - target)^2)

# 例如
pred = [0.001, -0.002, 0.003]
target = [0.0, 0.0, 0.0]
MSE = mean([0.000001, 0.000004, 0.000009]) = 0.0000047
```

## 七、评估指标

```python
# 测试集评估
test_preds = model.predict(test_data)
test_targets = test_data['y']

# MSE (均方误差)
mse = mean((pred - target)^2)

# MAE (平均绝对误差)
mae = mean(|pred - target|)

# R² (决定系数)
r2 = 1 - sum((pred - target)^2) / sum((target - mean(target))^2)
# 范围: (-∞, 1], 越接近 1 越好
# = 1: 完美预测
# = 0: 与均值预测一样
# < 0: 比均值预测更差

# 比赛特定指标
# panel R² (全局 R²)：在整个测试集上一次计算（不分日期）
panel_r2 = 1 - sum_all((pred - target)^2) / sum_all((target - mean(target))^2)
```
